# Studio Ghibli App 🎬

A Flutter mobile app for browsing Studio Ghibli movies, with offline data storage and favorites.

## Features

- Browse movies from the Studio Ghibli API
- Store data locally for offline access
- Manage favorite movies
- Firebase Analytics and Crashlytics integration

## Tech Stack

**Framework:** Flutter, Dart  
**API:** REST API, HTTP  
**Local Storage:** SQLite  
**Firebase:** Analytics, Crashlytics

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK

### Run locally

```bash
git clone https://github.com/jagudes/App_Ghibli_API.git
cd App_Ghibli_API
flutter pub get
flutter run
```

Run the app on a configured emulator or connected device.
